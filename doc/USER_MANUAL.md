# NovelRead 用户操作使用手册 (User Manual)

## 🚀 快速上手与软件运行

NovelRead 提供了绿色解压即用的免安装版本与单文件便携版：
- **绿色解压版 (推荐)**：打开 `dist/NovelRead/NovelRead.exe`（启动速度仅 0.2 秒）；
- **单文件便携版**：双击运行 `dist/NovelRead.exe`。

所有用户配置文件（`config.json`）、SQLite 数据库（`novelread.db`）与下载的小说文件（`downloads/`）均严格静默存放在可执行文件所在的根目录下，**零污染、零产生任何外部系统残留**。

---

## 📖 核心功能使用指南

### 1. 🌐 全网书城与高并发搜书 (Tab 2)
- **搜索操作**：在搜索框输入小说名称或作者名称（例如“凡人修仙”、“忘语”），点击“搜索”或按回车键。
- **检索维度选择**：
  - `🔍 智能匹配 (书名/作者)`：自动判定关键词类型并智能加权；
  - `📖 按书名搜索`：优先筛选并精准匹配书名；
  - `👤 按作者搜索`：优先筛选并置顶该作者名下的所有作品。
- **流式响应与连通性视图**：搜索启动后，界面会自动切至连通性测试视图，实时展示全网 25 个书源的响应延迟与连通状态，并流式输出搜书结果。
- **合成格式选择**：支持选择 `📚 EPUB 电子书 (标准打包)`、`📄 单文件 TXT` 或 `📂 按章节拆分目录`，点击“📥 下载选中的小说”即可将任务加入队列。

### 2. 📥 多任务下载管理 (Tab 3)
- 实时显示各图书下载进度条、线程并发数（如 `并发线程数: 50`）与状态。
- 若网络波动抛出限流异常，系统会自动执行 **3 轮指数递增退避补章**，无需手动干预；任务完成后会自动加入“我的藏书”。

### 3. 📚 我的藏书与后台自动追更 (Tab 1)
- **开读小说**：双击任意小说行或点击“📖 摸鱼开读”，即可唤醒摸鱼窗口进行阅读。系统自动记录并还原上次阅读到的**第 X 章第 Y 行**。
- **本地图书导入**：支持点击“📂 导入本地电子书”或直接将电脑中的 `.txt` / `.epub` 文件拖拽至窗口中。
- **🔄 自动追更功能**：
  - 仅对通过网络下载的图书生效（书名显示为高亮紫色 `[🔄 追更中]`）；
  - 勾选“🔄 追更”后，后台独立线程将在软件启动 2 秒后及后续**每 30 分钟**自动检查最新章节，并自动追加合并落盘。

### 4. 🎨 23 种摸鱼伪装模式与无缝切换
- 在阅读窗口中点击 **鼠标右键**，在弹出的 `🎨 切换摸鱼伪装模式 ▶` 子菜单中可一键无缝切换为 Excel、Word、Terminal、Outlook、Swagger、Notion、Stock K线、DevTools 等 23 种办公界面。
- **🛡️ 全局老板键 (`Alt+Z`)**：按 `Alt+Z` 可在瞬间隐藏或恢复所有正在阅读的摸鱼窗口。
- **按键绑定与速度调节**：在“⚙️ 系统设置” Tab 中，可自由修改 23 种伪装模式的快捷键、翻页按键及自动滚动像素速度（`1.0 ~ 50.0 px/s`）。
