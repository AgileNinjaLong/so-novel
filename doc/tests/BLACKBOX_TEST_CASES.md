# Black-Box Test Cases

## 1. “老板键”及模式切换响应延迟测试 (Boss Key & Mode Switch Latency)
- **目标**: 确保切换模式 (Ctrl+1, Ctrl+2) 以及老板键隐藏/显示 (Alt+Z) 的响应速度在毫秒级别，无明显卡顿。
- **预置条件**: 载入一本体积较大的小说（如 5MB 以上 TXT）。
- **测试步骤**:
  1. 打开阅读窗口。
  2. 连续按下 `Alt+Z` 3 次，观察窗口隐藏与恢复是否有延迟感。
  3. 按下右键菜单或快捷键，切换到另一种伪装模式。
- **预期结果**:
  - 隐藏与恢复应当瞬间完成（< 50ms）。
  - 模式切换应当直接复用内存中的书籍实例，瞬间展现新形态视图并定位到相同的阅读进度，不再出现解析卡顿。

## 2. 伪装模式视觉与独立配置测试 (Stealth Mode Visuals & Independent Config)
- **目标**: 确保不同模式下字体大小、颜色均被隔离保存，互不干扰，并且根据模式特性自适应背景。
- **预置条件**: 初始状态下开启 IDE 模式与悬浮模式。
- **测试步骤**:
  1. 在 IDE 模式下，打开设置，调整字体颜色为 `#00FF00` (绿色)，字体大小为 `18`。
  2. 关闭应用并重启，观察 IDE 模式。
  3. 切换至 悬浮窗模式，观察其字体颜色与大小。
  4. 调整悬浮窗模式的字体颜色为 `#FF0000` (红色)，大小为 `12`。
  5. 再次切回 IDE 模式。
- **预期结果**:
  - 重启后，IDE 模式保留绿字与大小 18。
  - 切换至悬浮模式时，字体大小和颜色应为其自身默认值，而非 IDE 的配置。
  - 设置并切回后，两者配置互不干扰，颜色和大小独立记忆。

## 3. 全局边缘拉伸功能测试 (Global Edge Resizing)
- **目标**: 确保所有支持无边框的阅读模式（IDE、CAD、Floating、Excel 等）的 8 个边缘与角落均能顺畅拉伸，且鼠标事件不会被内部控件拦截吞噬。
- **预置条件**: 开启具有全覆盖型子控件的模式（如 IDE 模式的 QTextEdit 或 Excel 模式的 QTableWidget）。
- **测试步骤**:
  1. 将鼠标移动至窗口右下角边缘，观察光标是否变为拉伸箭头（↘）。
  2. 拖拽边缘，调整窗口大小。
  3. 分别测试上下左右 4 个边，以及 4 个顶角的拉伸。
- **预期结果**:
  - 所有边缘及角落均应正确触发拉伸事件。
  - 内部文本域控件不会吞噬边缘处的鼠标按下和拖动事件。
  - 窗口拉伸后，界面布局不应出现黑边或排版错乱。

## 4. 动态自适应排版与重绘测试 (Dynamic Auto-adaptive Layout)
- **目标**: 确保字体大小与窗口宽度变化时，排版（每行字数）能够动态自适应，不发生文字截断或溢出。
- **预置条件**: 载入中文与英文字符混合的小说文本。
- **测试步骤**:
  1. 在某阅读模式下，缩小窗口宽度至仅能容纳 10 个中文字符。
  2. 观察当前段落的自动折行表现。
  3. 打开设置，将字体大小从 12 调整为 24。
  4. 观察界面刷新。
- **预期结果**:
  - 窗口变窄时，行内字符应当根据当前可视宽度进行重切分换行（Reflow）。
  - 字体变大后，单行能容纳的字数自动减少，所有文本重新根据新字体大小与容器宽度进行换行计算。
  - 翻页与自动滚动时，不应出现半个字符或溢出容器显示边界的情况。
